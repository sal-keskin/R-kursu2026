# R ile Halk Sağlığında Veri Analizi

Hacettepe Üniversitesi Tıp Fakültesi Halk Sağlığı Anabilim Dalı, Epidemiyoloji Bilim Dalı için hazırlanan R eğitiminin ders klasörü. Eğitim, SPSS ve Excel kullananlar için hazırlanmıştır.

**Kurs sitesi:** https://sal-keskin.github.io/R-kursu2026/

## Başlamadan önce

1. [CRAN](https://cran.r-project.org) sitesinden R'ı indirip kurun.
2. [RStudio Desktop](https://posit.co/download/rstudio-desktop/)'ı indirip kurun.
3. Ders klasörünü indirin: [R_egitim.zip](https://sal-keskin.github.io/R-kursu2026/indir/R_egitim.zip).
4. Zip dosyasını açın. `R_egitim` klasörünü yolunda Türkçe karakter ve boşluk olmayan bir yere taşıyın.
5. `R_egitim.Rproj` dosyasına çift tıklayarak projeyi açın.

Şimdilik paket kurmanız gerekmez; gereken paketleri oturumlarda birlikte kuracağız.

## Klasörün içeriği

| Dosya | İçerik |
|---|---|
| `R_egitim.Rproj` | RStudio proje dosyası |
| `oturum1_ilk_adim.R` | İlk oturumun kodu |
| `seminer_verileri.R` | Sonraki oturumlar için açık verileri indirme |
| `veri/` | Veri setleri ve değişken sözlüğü (`veri_sozlugu.xlsx`) |
| `OKUBENI.txt` | Klasörün kullanımı |
| `site/` | Kurs sitesinin kaynağı; katılımcıların kullanması gerekmez |

## Veriler hakkında

`veri/` klasöründeki bütün veriler eğitim için üretildi; gerçek kişilere ait değildir. Sayılar resmî istatistik değildir.
